# Computação-em_nuvem-aula1

Nesta atividade, utilizamos o Killercoda para acessar um ambiente Linux remoto por meio do navegador. O objetivo foi conhecer o ambiente e praticar comandos básicos do sistema operacional Linux.

Inicialmente, verificamos informações da máquina, como usuário (whoami), nome do computador (hostname), versão do kernel (uname -a) e sistema operacional (cat /etc/os-release). Foi identificado que o ambiente utiliza Ubuntu 24.04.4 LTS.

Em seguida, criamos o diretório computacao-nuvem para organizar os arquivos da atividade. Dentro dele, praticamos a criação de arquivos e a inserção de informações utilizando os comandos echo, > e >>. Também utilizamos o comando cat para visualizar o conteúdo dos arquivos.

Além disso, verificamos os recursos disponíveis no ambiente utilizando nproc, free -h e df -h, identificando a quantidade de CPU, memória RAM e espaço em disco disponíveis.

Por fim, criamos o arquivo grupo.txt com informações sobre os integrantes, a disciplina, o ambiente utilizado e o sistema operacional.

A atividade serviu como uma introdução prática ao Linux e aos ambientes computacionais remotos, permitindo compreender comandos básicos de terminal e observar os recursos de uma máquina disponibilizada em um ambiente de computação em nuvem.
